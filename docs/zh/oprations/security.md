# 安全与认证
Slive 会处理WEBDav访问令牌、平台Cookie、Firebase等敏感数据，所以用户应该设置加密保护自身数据安全。

## 注意事项
Slive **v1.8.15**及以后版本使用了新的密钥存储方式。

Slive 会为每一个用户生成一个独一无二的密钥并将其存储到系统特定的区域中，使敏感数据无法轻易被破解，这也会导致部分厂商判断为风险，请自行斟酌。

只加密第三方敏感数据，不加密所有数据。加/解密数据量极少，性能影响微乎其微。

密钥是base64编码32字节形式的，你可以自行生成使用并保存。

点击生成密钥后，请选择复制妥善保存。

当数据为加密数据时，需要开启安全模式输入密钥，否则你的部分敏感数据会因为解密失败无法使用。

数据远程同步过程中，请保持本地远端数据加密格式一致，否则会出现数据损坏。

如果密钥忘了也没关系，你可以重新设置数据，会覆盖加密数据，注意这个操作会使原来所有加密数据不再可用。

点击重置数据按钮后, 请重启app，确保其他数据正常。

为了你的数据安全，请在可信源下载使用Slive, 不要下载第三方网盘分发的App。

## 漏洞处理
不要在公开 Issue 报告疑似漏洞，请使用[Github 私密漏洞报告]() 或发送邮件到我的邮箱,说明受影响版本、影响和已移除密钥的最小复现
