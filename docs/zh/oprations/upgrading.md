# 升级与回滚
软件数据库迁移在启动时执行且不可回退，因此升级前的WEBDav备份就是回滚边界
## 升级前
1. 阅读当前版本到目标版本之间的全部发布说明。
2. 确认安全密钥和数据加密格式
3. 通过WEBDav备份软件数据

## 通过 komi-store 或者 Obtainium 更新Slive
- 软件地址：[komi-store-github](https://github.com/komi-store/komi-store/releases)
- 软件地址：[Obtainium-github](https://github.com/ImranR98/Obtainium/releases)

## 通过Github Action 使用Slive开发版

## 回滚
使用新版或开发版出现问题，请卸载并清理本地数据后，安装旧版使用WEBDav恢复旧版数据
