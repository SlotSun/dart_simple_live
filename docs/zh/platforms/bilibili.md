# Bilibili

[Bilibili](https://www.bilibili.com) 是中国的视频和直播平台。

## URL 格式
``` 
https://live.bilibili.com/{房间号}
```

## 功能
- ✅ FLV 和 HLS 流
- ✅ 弹幕采集
- ✅ 搜索
- ✅ 分类
- ✅ 多画质选项
- ✅ 登录功能

## 认证

更高画质的直播流需要账号认证。

Bilibili平台目前支持三种登录方式：扫码登录(推荐)，手动设置Cookie，网页登录。


### 扫码登录(推荐)

1. 平台配置 → bilibili平台，点击登录后，选择**扫码登录**
2. 下载bilibili手机 App 扫码。
3. 登录完成后，会自动退出登录界面。
4. 平台配置页面显示你的bilibili用户名，则代表登录成功。

### 手动设置 Cookie

平台配置 → bilibili平台，点击登录后，选择**Cookie登录**，在弹窗处粘贴已登录浏览器会话的 Cookie：

| Cookie | 必需 | 说明 |
|--------|------|------|
| `SESSDATA` | 是 | 会话令牌 |
| `DedeUserID` | 可选 | 用户 ID；弹幕会以该账号身份连接 |

### 网页登录

1. 平台配置 → bilibili平台，点击登录后，选择**Web登录**
2. 输入账号，验证码选择登录后，会自动跳转

## 注意事项

::: warning
登录后仍然无法观看1080P及以上画质或无法搜索，可能是账号或ip被风控了
:::
