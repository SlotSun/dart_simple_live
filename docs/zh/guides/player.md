## 快捷键
| 分类 | 功能 | 快捷键 | 说明 |
|:---|:---|:---:|:---|
| 窗口全屏/全屏 | 弹出设置 | `Alt + ,` | 屏幕右上角弹出设置 |
| 窗口全屏/全屏| 弹出关注 | `Alt + .` | 屏幕右上角弹出关注|
| 窗口全屏/全屏| 弹出SC | `Alt + /` | 屏幕右上角弹出SC |
| 窗口全屏 | 窗口全屏 | `F11` | 进入/退出窗口全屏模式 |
| 全屏 | 退出 | `ESC` | 退出全屏模式 |
> **说明**
> 
> 后续开发如果允许用户自定义快捷键，由于中文输入法冲突，请强制 `Alt + ,` 或者 `Ctrl + ,` 形式录入
